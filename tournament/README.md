# Tournament Management System

A complete, production-grade Tournament Management System featuring player registration, franchise bidding auctions, round-robin fixture generation, automated standings calculation via SQL and Python, JSON/CSV exports, and dual interfaces (CLI and Flask Web UI).

---

## Installation

Ensure Python 3.10+ is installed, then install dependencies:

```bash
pip install -r requirements.txt
```

> **Note**: The SQLite database file (`tournament.db`) is automatically created on first run via `init_db()`.

---

## How to Run

### Command-Line Interface (CLI)
```bash
python main.py
```

### Flask Web Interface
```bash
python app.py
```
Open your browser and navigate to: [http://127.0.0.1:5000](http://127.0.0.1:5000)

### Populate Seed Data (Optional)
To preload administrative accounts, teams, and players:
```bash
python seed.py
```

---

## Demo Flow

1. **Database Initialization**: Launching the CLI or Web UI automatically checks and applies the frozen SQLite schema.
2. **Authentication**: Register a new user or log in with default credentials (`admin`/`admin` for administrator or `owner`/`owner` for franchise owner).
3. **Franchise Registration**: Add franchise teams specifying their owner, purse budget, and maximum squad size.
4. **Player Roster**: Register players with designated positions (Batsman, Bowler, All-Rounder, Wicket-Keeper) and base auction prices.
5. **Live Auction**: Conduct live bidding in the auction arena. Deducts player prices from franchise purse budgets and checks roster caps.
6. **Fixture Generation**: Generate a full round-robin tournament match schedule across calendar dates.
7. **Score Entry**: Record fixture results (scores for both teams).
8. **Standings Calculation**: View the points table generated by SQL aggregates (`JOIN`, `GROUP BY`, `HAVING`, `CASE WHEN`) and ranked with Python lambdas.
9. **Export & Reports**: Export complete tournament state to `report.json` and standings to `points.csv`.
